# mezzrricki.github.io

GitHub Pages **user site** (published from branch `main`, folder `/`, legacy build). It hosts several small projects, each in its own
folder, so one repository serves many apps and purposes:

| Path | Project |
|---|---|
| [`/inkcore/`](https://mezzrricki.github.io/inkcore/) | Inkcore: a pen-first music notation app for Android tablets (home, privacy policy, support) |

To add another project, create a folder next to `inkcore/` with its own `index.html`, keep all links **relative** (so the folder works
at any address), and add a row to this table. Do **not** add a `CNAME` file to this repository: a custom domain on a user site makes
`mezzrricki.github.io` and every folder on it redirect to that domain.

See [`inkcore/README.md`](inkcore/README.md) for the Inkcore site: placeholders to fill in, images, how to publish, and how
`inkcore.app` redirects here.
